# Licencias y atribución (CC BY — principio no negociable)

Toda métrica y visualización deriva de fuentes con atribución obligatoria. La
UI debe mostrar estos créditos visiblemente.

| Fuente | Cita / DOI | Licencia |
|---|---|---|
| **WCVP** — World Checklist of Vascular Plants | Govaerts, R. et al. Royal Botanic Gardens, Kew. Snapshot GBIF DOI `10.15468/6h8ucr` | CC BY 4.0 |
| **IPNI** — International Plant Names Index | The International Plant Names Index, Royal Botanic Gardens Kew / Harvard Univ. Herbaria / ANBG | CC BY 4.0 |
| **GBIF** — occurrences | GBIF.org occurrence download (DOI generado por descarga, ver `data/raw/manifest.json`) | por dataset (mayormente CC BY / CC0) |
| **Kew Tree of Life / PAFTOL** | Baker, W.J. et al. Royal Botanic Gardens, Kew | CC BY 4.0 |
| **POWO** — Plants of the World Online | Royal Botanic Gardens, Kew | CC BY (API) |
| **Pl@ntNet** | Pl@ntNet identification API | términos del servicio |
| **geoBoundaries** (gbOpen PER ADM1) — límites departamentales para el join espacial backend | Runfola, D. et al. (2020) *geoBoundaries: A global database of political administrative boundaries.* PLoS ONE 15(4). William & Mary geoLab | CC BY 4.0 |
| **peru-geojson** (juaneladio) — geometría simplificada para la coropleta web | Juan Eladio Sánchez, repo `juaneladio/peru-geojson` | ver repo |

El DOI reproducible de cada descarga GBIF queda registrado automáticamente en
`data/raw/manifest.json` al correr `atlas download --full`.
